Sunset notice

No, it is not peak Claude hours.

Anthropic removed the Claude Code peak-hours limit reduction for Pro and Max accounts and doubled Claude Code's five-hour rate limits for Pro, Max, Team, and seat-based Enterprise plans on May 6, 2026.

This tracker used to exist because a weekday 5am–11am PT peak window affected Claude Code usage. Since that rule has been reverted, there is no longer a peak-hours schedule to calculate. The site is intentionally kept as a small historical marker instead of a live countdown.
